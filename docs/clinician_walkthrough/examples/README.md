# Educational demonstration cases (not the resident-validation study)

These snapshots support the clinician walkthrough in the root [`README.md`](../../README.md). They were generated with the same structured pipeline as the study cases, using `app/services/generation.py` and without calling OpenAI, because `OPENAI_API_KEY` was empty. Sequences 901 through 904 and seed 20260926 identify this teaching run. OpenAI is optional in the CliniProof pipeline and is used only to help word narrative text from clinical facts that have already been selected by the structured generator. These demonstrations are not wholly generated by a language model.

Those identifiers are not `VAL-*` study IDs. They are not members of the active prospective sets `CLINIPROOF_BALANCED_V4` (VAL-701–VAL-724) or `CLINIPROOF_SEEDCASES_V3` (VAL-801–VAL-824). Archived historical freezes, including `CLINIPROOF_TAXONOMY_V1` (VAL-201–VAL-224), are also separate. The teaching seed `20260926` with sequences 901–904 is not the seed-guided study batch, which uses the same master seed with sequences 1501–1524.

The table below lists the four teaching files. Three are clean charts for clinician teaching. The fourth plants one medication omitted at discharge (`f1_omission`) and is investigator-only. Do not give the fourth file to resident study participants.

| File | Internal id | Scenario | Error injection | Audience |
| --- | --- | --- | --- | --- |
| [`syn-000901.json`](syn-000901.json) | `SYN-000901` | Heart-failure inpatient (`HF_INPATIENT`) | none (clean) | Clinician teaching |
| [`syn-000902.json`](syn-000902.json) | `SYN-000902` | Atrial fibrillation with anticoagulation (`AF_ANTICOAGULATION`) | none (clean) | Clinician teaching |
| [`syn-000903.json`](syn-000903.json) | `SYN-000903` | Community-acquired pneumonia inpatient (`CAP_INPATIENT`) | none (clean) | Clinician teaching |
| [`syn-000904.json`](syn-000904.json) | `SYN-000904` | Heart-failure inpatient (`HF_INPATIENT`) | one medication omitted at discharge (`f1_omission`; Family 1) | **Investigator-only teaching** |

`SYN-000904.json` includes the planted-error answer key. Do not give that file, or the investigator-only README section that quotes it, to resident study participants. It is not a `VAL-*` case, but it teaches the injection method.

The commands used after database initialization and reference bootstrap were:

```bash
clinical-case-generator generate-synthetic-cases --count 1 --seed 20260926 --start-index 901 --scenario HF_INPATIENT --no-inject-error
clinical-case-generator generate-synthetic-cases --count 1 --seed 20260926 --start-index 902 --scenario AF_ANTICOAGULATION --no-inject-error
clinical-case-generator generate-synthetic-cases --count 1 --seed 20260926 --start-index 903 --scenario CAP_INPATIENT --no-inject-error
clinical-case-generator generate-synthetic-cases --count 1 --seed 20260926 --start-index 904 --scenario HF_INPATIENT --inject-error --error-category f1_omission
```

Each case seed is `{seed}:{sequence}:{scenario}`. For example, the heart-failure teaching case uses `20260926:901:HF_INPATIENT`.

Until a clinician finishes review, treat these records as machine-validated synthetic cases pending clinician validation.
