# Teaching charts

These charts support the [clinician walkthrough](../README.md). They are educational demonstrations. They are not members of the current prospective sets CLINIPROOF_BALANCED_V4 (VAL-701–VAL-724) or CLINIPROOF_SEEDCASES_V3 (VAL-801–VAL-824).

| Chart | Teaching id | What it shows |
| --- | --- | --- |
| [Heart failure, clean chart](clean_heart_failure_case.md) | TEACH-001 | A complete readable inpatient chart |
| [Heart failure, second chart](heart_failure_omission_case.md) | TEACH-002 | The same hospitalization with one difference on the discharge list |

Read the charts as clinical documents. The walkthrough explains the sections, the medication transition, and how the two charts differ. The investigator record for TEACH-002 is separate from the chart and is listed at the end of the walkthrough.
