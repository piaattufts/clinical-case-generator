# Documentation index

The project overview for every audience is the root [README](../README.md). That page explains what CliniProof studies, what a resident will eventually do, what Round 2 asks a clinician to validate, and how those cases were derived from Round 1. Start with Round 2 version 4. Set 1 and Set 2 both passed the internal task-validity and clinical-sufficiency gates and are prepared for clinician review. They are not clinically validated. Round 2 contains 24 study slots, VAL-801–VAL-824. Round 1 is the earlier validation round that led to that redesign. The method is [combined clinician revision](combined_clinician_revision_method.md). Case-set homepages for the frozen sources are [balanced](../data/case_sets/balanced/README.md) and [seed-guided](../data/case_sets/seed_guided/README.md).
