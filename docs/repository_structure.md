# Repository structure

```text
app/                         application and generation code
data/bootstrap/              terminology manifest, scenarios, and curated regimens
data/seed_cases/             resident source documents and derived archetypes
data/validation_balanced_v4/ active balanced structured batch
data/validation_seedcases_v3/ active resident-seed-guided batch
data/validation_balanced_v3/ frozen pre-regimen-QC balanced batch
data/validation_seedcases_v2/ frozen pre-regimen-QC seed-guided batch
data/validation_balanced/    earlier balanced preclinical freeze (V2)
data/validation_seedcases/   earlier seed-guided preclinical freeze (V1)
data/validation/             historical CLINIPROOF_TAXONOMY_V1 freeze
data/validation_comparison/  descriptive comparison of the two active batches
docs/                        authoritative project documentation
tests/                       automated tests
scripts/                     documentation and maintenance checks
```

## Source of truth versus generated files

| Kind | Examples | How to treat them |
| --- | --- | --- |
| Source of truth | `app/`, `data/bootstrap/`, `data/seed_cases/blueprints/`, `data/seed_cases/resident_authored/`, batch `batch_plan.json`, `data/validation_registry.json` | Edit these to change future generation. Do not edit a frozen plan in order to change cases that were already frozen. |
| Generated study artifacts | resident JSON, investigator JSON, manifests, coverage reports, diversity reports, readable packets | Regenerated by freeze, export, and `python -m app.services.readable_packets`. Do not hand-edit a frozen batch. |
| Authoritative docs | `docs/*.md`, root `README.md`, `data/README.md`, `data/active_validation_sets.md`, active batch READMEs | Describe the artifacts. Counts that are also in a manifest are checked by `scripts/check_docs.py`. |
| Historical catalogs | READMEs under earlier `data/validation*` directories | Kept so old links still resolve. They are not instructions for the current review. |

The two active batch directories are the only prospective review sets. Historical directories stay where they were frozen so their paths remain stable.
