# Reporting completeness

Each proportion is the share of included deployments or scenarios with a definite code or a non-empty free-text value other than NOT_REPORTED_OR_UNCLEAR. For tri-state fields, both YES and NO count as definite reports. These proportions are not added into a quality score.
