These 48 JSON files are the canonical clean cases for the current study. Each resident file and each evaluator file is a byte-identical copy of the recovered pre-injection chart that was previously stored under `exports/clean_balanced_seed_set/`.

They are not the original frozen `CLINIPROOF_SEEDCASES_V3` files. Those frozen files remain in the parent directory and include the planted medication-reconciliation changes. The next clinician revision starts from this directory.

VAL-701 through VAL-724 are not part of this clean base. SHA-256 values are in `docs/source_integrity.md`.
